# Official VUB title font

Place the licensed ITC Avant Garde Gothic Pro **Bold** OpenType font here as:

    ITCAvantGardePro-Bold.otf

The template loads this file automatically, including on Overleaf. If your
licensed font has another filename, rename the file to the name above; its
internal font name does not need to change. Use an actual Bold OTF font.

The font binary has not yet been supplied. The current PDF uses **TeX Gyre
Adventor Bold**, an explicitly documented substitute available in TeX Live.
Libertinus Serif and Libertinus Math remain unchanged.

VUB's official brand page explains how to obtain its font package from MarCom:
https://www.vub.be/en/about-vub/key-data-vub/visual-identity-vub

Before publishing a font binary in a public repository or distributing it in a
ZIP, check the permissions accompanying the supplied font package. This folder
contains no extracted, reconstructed, or unofficial copy of the font.
